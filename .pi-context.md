## Docker rebuild notes
- Docker caches COPY layers aggressively
- When web/ files change, you MUST invalidate the cache:
  ```
  docker compose -f OpenDCC/docker/docker-compose.yml build --no-cache rocky9
  docker compose -f OpenDCC/docker/docker-compose.yml build rocky9-gpu
  docker compose -f OpenDCC/docker/docker-compose.yml up -d rocky9-gpu
  ```
- Or touch a file before build: `touch OpenDCC/web/server.py`
- rocky9-gpu depends on opendcc:rocky9 image — rebuild rocky9 FIRST

## Known issues / notes
- usd-viewer (needle-tools) is cloned at Docker build time into /opt/usd-viewer
- GPU snapshot uses subprocess isolation (_render_worker.py) — USD HgiGL may
  "double free" at cleanup but PNG is written before crash, server unaffected
- EGL requires **Compatibility profile** (not Core) — USD 24.11 HgiGL queries
  legacy GL state that is invalid in core profile (GL_POLYGON_SMOOTH etc.)
- RTX 5090 Blackwell / driver 595.45 validated ✓

## GPU Snapshot architecture
- `egl_headless.py` — reusable EGL context init (platform device, compat profile)
- `_render_worker.py` — isolated subprocess: EGL init → USD FrameRecorder → PNG
  Two modes: `--probe` (health check) and `--usda`/`--output` (actual render)
- `render_snapshot.py` — exports stage to temp USDA, spawns worker, reads PNG
- `/health` → `snapshot_available` based on real subprocess probe (not just imports)
- Frontend shows 📷 button only when `snapshot_available === true`
