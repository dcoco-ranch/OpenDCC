## Environment
- **Development machine**: macOS (Apple Silicon) — code editing & git only
- **Docker runtime**: Remote VM Rocky Linux 9 — ALL Docker builds & runs happen THERE
- **NEVER attempt** to run docker, colima, or server.py locally on macOS
- **NEVER attempt** to curl localhost — the server runs on the VM, not here

## Build & Run (on the Rocky 9 VM)
- Web-only (fast):  `docker compose -f docker/docker-compose.yml up rocky9-web`  → port 8082
- Full USD build:   `docker compose -f docker/docker-compose.yml up rocky9`      → port 8080
- GPU variant:      `docker compose -f docker/docker-compose.yml up rocky9-gpu`  → port 8081
- Build context is `ShapeFX/` (parent of `OpenDCC/`)

## Architecture
- 34 C++/Qt packages in `src/packages/` — desktop app (NOT used by web yet)
- Web frontend: single-page `web/static/index.html` (Three.js + USD WASM)
- Web backend: `web/server.py` (FastAPI + pxr or stub mode)
- USD→glTF: `web/usd_to_gltf.py`
- Docker: `docker/Dockerfile.rocky9` (full), `docker/Dockerfile.rocky9.web` (light)
