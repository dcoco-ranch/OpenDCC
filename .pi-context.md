## Key Technical Notes
- Three.js r163: use scene.add(gizmo) not getHelper() (r169+)
- Hydra WASM delegate: matrixAutoUpdate=false → must decompose before gizmo attach
- Hydra flattens all meshes under usdRoot, strips path to last segment for mesh.name
- Don't modify obj.position before gizmo.attach() — causes mesh offset
- GPU snapshot: EGL Compatibility profile (not Core) for USD 24.11 HgiGL
- Snapshot subprocess: crash-safe (double-free at cleanup is normal)
- Z-up stages: Three.js applies rotation.x=-π/2, snapshot worker undoes it
- Context7 extension: MCP over HTTP at https://mcp.context7.com/mcp
- Ctrl+Z wireframe conflict: Z without Ctrl = wireframe, Ctrl+Z = undo
